# syntheticspeech
Master thesis project "Improving African-accented English speech recognition with synthetically generated speech data"

See [the multi-model comparison guide](cloning/COMPARISON.md) for Qwen3-TTS,
XTTS-v2, Afro-TTS, and Azure Nigerian English synthesis, downloads, grouped
recordings, tests, and local Docker build instructions. The original
[Qwen pilot](cloning/README.md) remains available.
